## 📌 About the Project

This repository contains a practical Python project focused on **analyzing customer survey feedback and ratings**.

The notebook demonstrates how to organize feedback data, clean written responses, identify frequently used words, calculate average ratings, and sort feedback based on customer ratings.

The project uses a sample dataset containing customer names, written feedback, and ratings on a scale of 1 to 5. It also allows users to add new feedback entries interactively.

---

## 🎯 Topics Covered

### 📝 Feedback Data Management

The notebook covers:

- Creating a feedback dataset using a Python dictionary
- Storing customer names, feedback, and ratings
- Maintaining serial numbers for feedback entries
- Adding new feedback using user input
- Updating the dataset dynamically

### 🧹 Text Cleaning

Practical examples demonstrate:

- Removing selected punctuation marks
- Removing unnecessary spaces
- Standardizing spaces between words
- Converting feedback text to lowercase
- Updating the original feedback data with cleaned text

### 🔍 Word Count Insights

The notebook demonstrates how to:

- Define a function to count words across feedback entries
- Search for specific words in customer feedback
- Count feedback entries containing **"good"**
- Count feedback entries containing **"poor"**
- Count feedback entries containing **"excellent"**

### ⭐ Rating Analysis

The project covers:

- Calculating the total of customer ratings
- Counting the number of feedback entries
- Computing the average customer rating
- Rounding the average rating to two decimal places

### 📏 Longest Feedback Analysis

The notebook demonstrates:

- Counting words in each feedback entry
- Comparing word counts across responses
- Identifying the longest feedback
- Displaying the longest feedback and its word count

### 🔤 Unique Word Extraction

The notebook demonstrates:

- Splitting feedback into individual words
- Extracting unique words from cleaned feedback
- Avoiding duplicate words in the resulting list
- Storing distinct words in a Python list

### 📊 Sorting Feedback by Rating

The notebook covers:

- Combining feedback details using `zip()`
- Sorting feedback entries based on customer ratings
- Using `sorted()` with a custom sorting key
- Arranging feedback from highest to lowest rating
- Displaying the sorted feedback entries

## ▶️ How to Run the Project

1. Clone or download this repository.
2. Open `Survey_Feedback_Analyzer.ipynb` in Jupyter Notebook or Google Colab.
3. Run the notebook cells in order.
4. Enter the number of additional feedback entries when prompted.
5. Provide the customer name, written feedback, and rating for each new entry.
6. Run the remaining cells to explore the cleaned feedback, word count insights, average rating, longest feedback, unique words, and sorted results.

**Requirements:**

Python 3.x and Jupyter Notebook or Google Colab. The notebook uses Python's built-in functionality and does not require additional third-party libraries.
